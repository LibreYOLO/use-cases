# Quickstart. Detect objects in 2 minutes. 100% MIT.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/LibreYOLO/use-cases/blob/main/quickstart/predict.ipynb)
[![PyPI](https://img.shields.io/pypi/v/libreyolo?label=libreyolo)](https://pypi.org/project/libreyolo/)
[![License](https://img.shields.io/badge/license-MIT-green)](../LICENSE)

The first two minutes with LibreYOLO, in one notebook: install it, detect objects in an image with a pretrained YOLOv9 model, and export the model to ONNX. A free Colab CPU runtime is enough.

| Notebook | What it does |
|---|---|
| [`predict.ipynb`](predict.ipynb) | Install, detect objects in an image, print the boxes, export to ONNX and run the exported model |

Tested with `libreyolo` 1.6.0.

To train on your own data, see the [training guide](https://www.libreyolo.com/docs/train).
